StudioMCU portable package
==========================

Run StudioMCU.exe — it opens http://127.0.0.1:8000 in your browser.

Included beside this exe:
  lessons/      lesson starters and solutions
  static/       web UI (HTML/CSS/JS) and logo
  firmware/     CMSIS/HAL/LL teaching headers
  simulation/   Renode board scripts
  toolchain/    ARM GCC + st-flash (for Build / Flash)

Optional:
  tools/renode/   portable Renode for Simulation mode 
  (Install Renode https://github.com/renode/renode/releases/download/v1.16.1/renode-1.16.1.setup.exe for simulation mode to work)
